### 🎯 Core Purpose

Build a robust academic scheduling system that enables students to:

- ✅ **Manage** multiple course schedules with unlimited capacity
- ✅ **Track** lectures, tutorials, and laboratory sessions across semesters
- ✅ **Detect** scheduling conflicts automatically with detailed reporting
- ✅ **Analyze** workload distribution across days and weeks
- ✅ **Optimize** academic planning for balanced study schedules
- ✅ **Export** schedules in multiple formats (CSV, visual tables)
- ✅ **Test** thoroughly with built-in test suites

```cpp

if (dynamic_cast<Lecture*>(originalLesson)) {
    lessonCopy = new Lecture(
        originalLesson->getType(),

        originalLesson->getStartHour(),
        originalLesson->getEndHour(),
        originalLesson->getClassroom(),
        originalLesson->getTeacherName(),
```

#### 2. Iterator-Based Safe Removal

```cpp
// Safe removal while iterating
vector<Lesson*>::iterator it = lessons.begin();
while (it != lessons.end()) {
    if (shouldRemove(*it)) {
        delete *it;  // Free memory
        it = lessons.erase(it);  // Safe erase
    } else {
        ++it;
    }
}
```

#### 3. Deep Copying Complex Objects

```cpp
// Preserve polymorphic object hierarchies
vector<Lesson*> lessonsBackup;
for (Lesson* original : originalLessons) {
```
